# Privacy

Lepidox is designed to operate locally in the browser.

- No analytics or advertising.
- No telemetry endpoint.
- No mandatory backend.
- No remote JavaScript execution.
- No password, MFA or credential storage.
- No `cookies` permission.
- Saved lists and metadata are stored using the browser extension storage APIs.
- Runtime tab identifiers are stored only in extension session storage.
- URLs configured by the user are not transmitted by Lepidox to a third-party service.

When Lepidox opens a configured website, that website continues to operate according to its own privacy, authentication and network policies.
