# Contributing to Lepidox

Contributions are welcome.

1. Fork the repository.
2. Create a focused branch (`feature/...` or `fix/...`).
3. Keep browser permissions minimal.
4. Do not add telemetry, credential collection, remote executable code or third-party runtime dependencies without prior design discussion.
5. Test changes in both Chrome and Microsoft Edge.
6. Submit a pull request describing behavior and security/privacy impact.

Source files should retain the SPDX identifier `MPL-2.0` when practical.
