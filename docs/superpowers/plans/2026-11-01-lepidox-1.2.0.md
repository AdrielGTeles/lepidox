# Lepidox 1.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Lepidox 1.2.0: rotation survives updates and browser restarts, real load-failure detection, toasts that never cover the UI, wall-screen options (own full-screen window, keep display awake, reload before showing, per-screen zoom) and a donation link.

**Architecture:** The service worker keeps owning the rotation (`rotation-manager.js`, everything under `exclusive`). A v2 recovery record in `chrome.storage.local` lets the worker adopt existing tabs after an update or a restored session. `webNavigation` errors feed the existing per-entry status. Pages keep rendering from `storage.onChanged`; `toast()` becomes a single in-flow slot.

**Tech Stack:** Plain ES modules, Manifest V3, no dependencies, `node --test` with `tests/chrome-mock.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-01-lepidox-1.2.0-design.md`

## Global Constraints

- No dependencies, no build step; repo root is the extension.
- New permissions exactly: `webNavigation`, `power`. Nothing else.
- `_locales/en` and `_locales/pt_BR` keep identical key sets (`npm test` enforces).
- `minimum_chrome_version` stays `120`.
- Version `1.2.0` in `manifest.json` and `package.json`.
- Copy: short, direct; no defensive claims in UI or store text.
- Donation URL: `https://buymeacoffee.com/adrielgtelj` (slug `adrielgtelj`).
- Files keep the `// Copyright (c) 2026 Adriel Teles` + `SPDX-License-Identifier: MPL-2.0` header.
- Exported lists keep `format: "lepidox-lists", version: 2`.

## Review Focus

1. The user closes the own full-screen window → session ends like any closed window; auto-resume record kept with `live: false`. (Task 4 test.)
2. An SSO redirect chain that aborts a navigation (`net::ERR_ABORTED`) must not flag the screen. (Task 2 test.)
3. `setZoom` rejected by the browser (PDF, error page) must not break the rotation. (Task 5 test: mock throws, rotation continues.)
4. An update arriving after the rotation window was closed (`live: false`) starts nothing. (Task 3 test.)
5. A toast replaced while hovered: the new one still expires; Undo after switching lists restores into the original list. (Task 6 E2E check.)
